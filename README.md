# 论文体检 · Thesis Checkup

在浏览器本地检查 Word 论文格式，生成可视化体检报告，并直接修复可自动修复项。

文件不上传、不依赖账号，解析与修复都在本地完成。

## 它解决什么问题

毕业设计提交前，格式问题往往会反复消耗学生和导师的时间：页边距差 5 毫米、正文不知何时变成了五号、图题没居中、参考文献编号断档。肉眼很难发现，但形式审查会。

现有工具要么把论文上传到云端，要么只支持单一学校规则，或者只给一份问题列表、不负责修复。这个项目尝试把流程做成：

```text
拖入 .docx → 解析 OOXML → 按规则包体检 → 可视化定位 → 生成修复副本 → 复检
```

## 功能

- **纯本地解析**：JSZip + OOXML，读取样式继承、节、页边距、页眉页脚、目录域，文件不离开浏览器。
- **52 条规则**：页面与页码、正文、标题层级、图表题注、参考文献、结构完整。
- **规则包**：内置「天大本科（参考）」与「通用中文论文」，也可以按表单创建自己的学校规则。
- **体检报告**：百分制评分、分类得分、格式指纹、逐段 X 光、问题定位、HTML 报告导出。
- **一键修复**：页边距、字体、字号、行距、缩进、对齐、题注、标题、参考文献格式、致谢/附录分页、页码域。
- **TOC 重建**：可选，把静态目录替换为真正的目录域；默认不勾选，避免误删。
- **体检卡**：生成 1080×1440 PNG，方便保存或分享。
- **PWA**：构建版可安装到桌面，断网也能打开并加载示例。
- **测试样本**：带错误的示例论文、满分论文，以及已有页脚、多节、TOC 域三份结构样本。

## 快速开始

要求 Node.js 22+。

```bash
npm install
npm run dev
```

打开 http://localhost:5188 。

构建：

```bash
npm run build
npm run preview
```

## 怎么用

1. 拖入 `.docx`，或点「加载示例论文」。
2. 查看评分、分类得分和问题列表；点「定位」看逐段格式。
3. 点「生成修复版」，选择要修复的项，下载新副本。
4. 点「查看修复后报告」复检。
5. 如果学校不是天大，点「设置我的学校格式」，按表单填页边距、正文字体字号、行距、标题字号等。

「看一份满分样例」可以查看全部规则通过时的报告。

## 自定义学校规则

默认入口是表单，不需要懂 JSON：

- 规则包名称与简称
- 页边距四边（cm）
- 正文字体、字号、首行缩进、行距类型与数值
- 一级/二级/三级标题字体与字号
- 图表题注、参考文献标题/条目的字体与字号
- 是否要求中文摘要、英文摘要、关键词、目录、参考文献、致谢

表单覆盖不到 B5、Letter、特殊摘要标题字号等细节时，可以切换「JSON 高级模式」直接编辑完整规则包。

规则包保存在 `localStorage`，不会上传。

## 自动修复的边界

会自动处理：

- 纸张、页边距
- 正文中英文字体、字号、行距、首行缩进、对齐、段前段后
- 标题字体、字号、章前分页
- 图表题注字体、字号、居中
- 参考文献标题与条目字体字号
- 谢辞、附录另起一页
- 缺少页码时插入居中 `PAGE` 域
- 可选：静态目录重建为 `TOC` 域

不会自动处理：

- 查重、AIGC 检测
- 参考文献自动重编号与正文引用同步
- 文献类型 `[J]/[M]/[D]` 自动推断
- 目录页码刷新（需在 Word 中右键更新）
- 复杂修订、加密文档、WPS 特有样式

修复只改当前文字的直接格式，不重写样式表；之后新增的文字仍可能继承原样式。

## 项目结构

```text

  lib/
    docx.ts              DOCX / OOXML 解析与样式继承
    rules.ts             规则、评分与报告

  make_sample.py         生成带错误的示例论文
```

## 测试

```bash
npm test
```

当前 8 个用例，覆盖：

- 带错论文的规则命中
- 修复后复检与页码域写入

## 部署

仓库包含 `.github/workflows/pages.yml`：

- 仓库为 Private 时，构建与部署任务自动跳过。
- 仓库改为 Public 后，推送到 `main` 会自动构建并部署 GitHub Pages。
- 首次使用前，在仓库 Settings → Pages 中把 Source 设为 GitHub Actions。

构建产物在 `dist/`，已被 `.gitignore` 排除。

## 规则来源与免责声明

天大规则参考《本科生毕业设计（论文）统一格式的规定（试行稿）》。不同年份、学院、学位类型可能另有细则，规则包只是公开规范的工程化表达，不是学院官方审查结论。

提交前请以教务 / 研究生院最新模板为准。

## 已知限制

- 只支持 `.docx`；旧版 `.doc` 需先另存为 `.docx`。
- 复杂样式继承、文本框、修订记录、嵌套表格可能存在边界误差。
- 页码与目录域插入后，建议在 Word 中打开复核并更新域。
- 评分用于自查排序，不代表学院正式评分。
